# 基本使用

## 笔记管理

- 左侧列表显示当前仓库中的所有笔记
- 点击笔记名称 → 右侧预览
- 点击预览区的编辑图标 → 进入完整编辑器

## 新建笔记

点击左侧底部的 `+` 按钮，输入笔记名称即可创建。创建成功后自动进入编辑器。

## 编辑笔记

支持两种编辑模式：

- **Monaco** — Markdown 源码编辑，适合熟悉 Markdown 的用户
- **Quill** — 所见即所得编辑，类似 Word 的体验

可在编辑器右上角切换模式。

## 自动同步

默认自动同步，无需手动操作：

- 页面加载时自动 `git pull`
- 保存笔记时自动 `git commit` + `git push`

也可以点击顶部同步按钮手动触发。
